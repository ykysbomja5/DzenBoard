## 🚀 О проекте

**DzenBoard** — это современная веб-платформа для проведения онлайн-уроков. Она объединяет в себе бесконечный векторный холст, встроенные видео- и аудиозвонки WebRTC, совместный чат с поддержкой передачи файлов, а также набор математических и геометрических инструментов.

Проект разработан без громоздких внешних фреймворков: чистый **Go** на бэкенде и **Vanilla JS / CSS Glassmorphic** на фронтенде, что обеспечивает высочайшую скорость работы и минимальный отклик.

## ✨ Возможности

### 📞 1. Встроенные WebRTC P2P Аудио- и Видеозвонки
- **Прямая голосовая и видеосвязь**: Медиапотоки передаются напрямую между браузерами (P2P), не нагружая сервер.
- **Интерактивное модальное окно вызова**: Гармоничная мелодия входящего звонка (Web Audio API) и кнопки мгновенного ответа/отклонения.
- **Плавающий стеклянный виджет**: Drag-and-Drop видеопанель, которую можно перетаскивать в любой угол доски или сворачивать.
- **Speaking Detection**: Автоматическая подсвечивающаяся индикация активности микрофона вокруг аватаров участников.
- **Управление медиа**: Включение/выключение микрофона 🎙️ и камеры 📹 в один клик.

### 🧹 2. Двурежимный смарт-ластик
- **ПКМ (Правая кнопка мыши)**: Удаление **любого объекта целиком в 1 клик** (фигуры, графики, рукописные надписи, LaTeX-формулы, картинки).
- **ЛКМ (Левая кнопка мыши)**: Стандартный мазок кисти-ластика (стирает пиксели строго под курсором).

### 💬 3. Совместный чат с файловым обменом
- **Мультимедиа в чате**: Отправка текстовых сообщений, изображений, видеофайлов (с проигрыванием прямо в чате) и документов (`.pdf`, `.docx`, `.txt`).
- **Сохранение истории**: Сообщения сохраняются в SQLite и доступны при повторном входе.
- **Индикатор прочтения**: Красный уведомляющий бейдж при закрытом чате.

### 📐 4. Математические и геометрические инструменты
- **Интерактивные виджеты**: Подвижные и вращаемые **Линейка (📏)** и **Транспортир (📐)**.
- **Векторные фигуры**: Окружности, прямоугольники, треугольники, прямые линии, стрелки и координатные оси.
- **KaTeX LaTeX Editor**: Удобный редактор математических формул с мгновенным предпросмотром.

### 🌙 5. Тёмная и Светлая темы (Glassmorphic UI)
- Адаптивный дизайн с неоновыми анимированными туманностями на фоне.
- Автоматическая инверсия цвета чернил и координат при переключении темы.
- Сохранение предпочтений пользователя в `localStorage`.

### 👁️ 6. Режим «Следование за преподавателем»
- Преподаватель может транслировать позицию своего экрана и масштаб (Zoom) всем ученикам доски в реальном времени.

## ⚡ Быстрый запуск

### Требования
- Установленный [Go 1.22+](https://go.dev/dl/)

### Шаги установки

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/ykysbomja5/DzenBoard.git
   cd DzenBoard/mathboard
   ```

2. **Скомпилируйте и запустите сервер**:
   ```bash
   # Windows (PowerShell)
   $env:PORT="8090"; go run main.go

   # Linux / macOS
   PORT=8090 go run main.go
   ```

3. **Откройте приложение в браузере**:
   ```text
   http://localhost:8090/
   ```

## 🔍 SEO и Подготовка к Деплою

Платформа полностью оптимизирована для индексации в поисковых системах **Яндекс** и **Google**:
- **`robots.txt`**: Разрешает индексировать публичные страницы входа/регистрации и изолирует приватные комнаты уроков (`/board/*`).
- **`sitemap.xml`**: Карты сайта для поисковых ботов.
- **OpenGraph & Schema.org**: Структурированные данные `WebApplication` и превью-картинки для соцсетей.
